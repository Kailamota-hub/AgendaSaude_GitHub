# Vídeo de apresentação

A atividade solicita um vídeo de **no máximo 1 minuto** apresentando o projeto concluído.

Opções de entrega:

1. gravar o vídeo em MP4 e colocar nesta pasta, por exemplo `apresentacao-agendasaude.mp4`; ou
2. publicar como vídeo privado/não listado no YouTube e substituir o campo abaixo pelo link.

**Link do vídeo:** INSERIR_AQUI

O roteiro sugerido está em `docs/ROTEIRO_VIDEO_1_MINUTO.md`.
