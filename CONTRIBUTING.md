# Como contribuir

1. Clone o repositório.
2. Crie uma branch para sua alteração: `git checkout -b nome-da-alteracao`.
3. Faça uma melhoria real no projeto.
4. Execute o projeto e valide a mudança.
5. Faça commit com uma mensagem objetiva.
6. Envie a branch e abra um Pull Request, ou faça merge conforme o fluxo definido pelo grupo.

Todos os integrantes devem aparecer como colaboradores e possuir histórico de contribuições, conforme a atividade do Projeto Integrador.
